## Human vs AI Comparison

| Aspect | Human Version | AI Version |
|---|---|---|
| Readability | Easy to follow, but contains more code for booking and displaying appointments. | Simple and easy to read with clear variable names. |
| Correctness | Correctly stores and displays appointment information. | Correctly stores appointment information and returns the created appointment. |
| Simplicity | Uses a list, dictionaries, booking function, and display function. | Uses a simple list, dictionary, and one main function to add appointments. |
| Error Handling | Checks whether the patient name is empty, but has limited validation. | Does not include input validation or error handling. |
| Maintainability | Functions separate booking and displaying appointments, making the code easier to organise. | Simple structure makes it easy to understand and modify, but it would need more features as the system grows. |
